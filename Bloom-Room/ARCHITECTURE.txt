RoomBloom House Editor — 架構與 UI 修改指南
=========================================

資料流
UI → action → HouseEditor → domain systems → House Definition → SceneView
                                    ↓
                                Save / Export

只有 HouseEditor 協調狀態、撤銷和保存。DOM 按鈕不直接操作 Three.js mesh。
建造／碰撞／導航模組可在 Node 中測試，也能接另一套 UI 框架。

如何改 UI
1. 調整 house/house.css 內：
   .house-identity / .house-residents / .house-quiet-controls：全螢幕浮動控制
   --house-accent：主要顏色
   --house-control-bg：個別按鈕底色
   --house-scene-bg：全頁場景底色
   --house-toolbar-gap：工具間距
2. 修改 roomView()，重排 App 的房間資訊、成員與導航。
3. 修改 HouseUI.render()、catalog()、dialog()，重排工具和彈窗。
4. 保留必要容器：
   .house-shell、#house-stage、#house-editor-ui、#house-dialog、
   #house-message、#house-hover-hint、#house-pet-panel，以及 data-pet-* 狀態欄位。
5. 保留 data-h-action / data-h-setting 的語意值。
   業務邏輯不靠按鈕文字判斷，所以可自由改標籤與語言。

重要 actions（HouseEditor.dispatch）
edit / save（保存成功後離開編輯）

pet-status / close-pet / member {id}
家具 REST / FEED handler 直接呼叫 animal.go(type, objectId)，不顯示 Find / Wander 選單。

選單與偏好設定
HouseUI 的 .house-edit-dock 由上至下：依模式工具、layer switch + ! Reset、SAVE。
一般房間使用完整 viewport；房名、四角圖示及右側室友／貓咪列都是浮動 UI。
script.js 只在網站初次從預設入口開啟時恢復 lastRoom；離開按鈕與明確路由不被攔截。
SAVE 使用固定三欄網格，包含按鈕間距的整塊範圍都屬於選單；Type 選項絕對定位。
flyout 開合不改主按鈕與 canvas 尺寸；生命事件重新 render 也保留滑鼠所在 SAVE 的展開狀態。
滑鼠、鍵盤 focus/方向鍵和 touch 開合使用同一組選項；觸控常駐匯出／匯入。
EditorPreferences 以 roombloom-editor-preferences-v1 保存 layer/buildRotation/
height/finish/color，獨立於房屋 JSON；只接受明確欄位與合法值，讀取失敗使用預設。
Reset 與匯入保留模式、方向與 Texture 偏好；Type 不屬於偏好設定。
build 是可空值的當次建造類型；成功的一筆 stroke 結束後清空。
Object 放置、取消、切換模式與離開編輯都由 clearPlacement() 清空預覽類型。
舊偏好中的 build 會被忽略。Type 按鈕只展開選項，不會自動啟用上次工具。
R 旋轉 Structure 預覽：buildRotation 0/90/180/270，side 由角度選 N/W。
地板 optional rotation 欄位保存紋理方向；門選對應支撐牆，沒有支撐顯示紅色預覽。

輸入優先順序
家具預覽中右鍵 → cancel-tool；其他空白處拖曳 → 平移。
Structure 有效建造格左鍵 → stroke；結構上右鍵 → 拆除 stroke。
SceneView 在 pointermove 之間插值取樣，避免快速拖曳跳格，且每格只作用一次。
stroke-start / stroke-end 讓 HouseEditor 將整筆拖曳合併成一筆撤銷。
游標捕捉在 pointercancel、失焦和快捷鍵中止時釋放。
鍵盤由 HouseEditor 接收：Ctrl/Cmd+Z、Shift+Ctrl/Cmd+Z、R、M、Esc。
R/M 使用 KeyboardEvent.code（KeyR/KeyM），不依 IME 的 key 字元或 Process；沒有 code 才回退 key。
先排除文字欄位、contenteditable、modal 與修飾鍵，避免攔截文字組字。
雙指手勢不觸發點擊；觸控開始時延後建造，避免剛放第二指就誤建。
選取與 hover 使用不同 SelectionSystem；藍色為選取，棕色為 hover。
canvas.focus() 保留快捷鍵的輸入焦點；canvas:focus 取消整張畫布的原生外框，
按鈕與輸入欄位的 :focus-visible 樣式不受影響。

座標和牆
X/Z：-8..11 整數。
格中心 world = (x+0.5, y×0.5, z+0.5)；地板 y=0。
壁掛高度以 0.5 單位量化為 grid.y，同時保存 height。
牆在地板的 N/W 邊：
N：(x,z) → (x+1,z)
W：(x,z) → (x,z+1)
牆是格子間的邊，不占整個地板格。
Door 記錄 wallId 和 locked（目前固定 true，含舊資料遷移）；門模型關閉且尋路阻擋該邊。
拆牆也會移除門。
相同邊緣資料供畫面、碰撞和尋路使用。

占格
家具預設 size={x:1,y:1,z:1}。
footprint() 已處理矩形尺寸與 90° 旋轉，也會檢查跨格家具是否被牆切開。
第一版匯入尺寸必須符合 catalog；新增大型家具時修改 catalog 尺寸、
模型和 interactionPoints 即可沿用占格驗證。
壁掛保存 attachedWallId、height、grid、rotation；旋轉也會驗證垂直占用。
桌面物件保存 supportId（Table）與 supportSlot（0–3），只有 Catalog.tabletop=true 可放。
桌面位置由 SceneView 的桌面 raycast 計算，模型跟隨桌子旋轉且提高至 y=.73。
同一位置不可重疊；桌面物件不另外阻擋地面尋路。
結構修改後 PlacementCleanup.revalidate() 反覆清除失效家具至穩定，避免父子順序影響結果。
ObjectSystem.remove() 也清除已失去桌子支撐的物件。
沒有倉庫；撤銷快照仍能恢復刪除前的 ID 與 customState。
cat 是 Catalog 的單隻選項，實際保存於 animal，不進入靜態 objects。
編輯時不隨機遊蕩，但仍自動尋找可到達的食盆；失去支撐或被家具覆蓋會清除 animal.placed。
上床／沙發由合法相鄰格播放跳躍並提高模型位置；grid 保留走道格作為下次尋路起點。

共用 House Definition
format: "RoomBloomHouse"
version: 1
structure: {floors: [...], walls: [...], doors: [...]}
objects: [...]
materials: {[structureId]: {finish,color}}
animal: {id,name,placed,grid,lifeId,lastFedAt,health}
social: {isPublic,requests:[{id,authorId,text,createdAt,recipients:[{memberId,response,respondedAt}]}]}
assets: optional {[audioId]:{mime,data}} — 僅可攜式匯出，base64 音檔
lighting: {mode:"auto"|"manual",level:0..1}
weather: {mode:"auto"|"manual",kind:"sunny"|"rain"|"snow",nextChangeAt:timestamp}
metadata: {name,savedAt}

Weather: HouseFeatures owns the saved choice and 30–60 minute automatic clock.
SceneView draws a decorative weather canvas behind the opaque WebGL room and
shares an animated sky texture between Window panes. Precipitation never paints
over the house; it cannot receive pointer input. Reduced motion uses a still sky.
The render loop caps weather updates at 20 fps and stops when the room is hidden;
leaving the room removes the canvas, listener and shared texture.

家具欄位：
id / objectType / placement / grid / size / rotation /
attachedWallId / height / interactionType / interactionConfig / customState /
optional supportId / supportSlot

customState.image：畫框內嵌 data:image（設定一次，上限 250,000 字元）
customState.schedule：垃圾桶 order/nextIndex/intervalHours/nextDueAt/note/completedAt
customState.machines：{washer:[reservation],dryer:[reservation]}，各機器預約不可重疊
reservation：{id,memberId,startAt,endAt,startedAt?,completedAt?}；1–1,440 分鐘
Oven 使用 customState.machines.oven，與洗烘機共用驗證與預約邏輯。
customState.tasks：[{id,text,assignees,dueAt,createdAt,completedAt,completedBy?}]
customState.music：{tracks:[{id,name,duration,bytes,mime}],loop,volume,enabled?}

這是遊戲資料，不是 Scene.toJSON()。
不保存 DOM、mesh、材質實例、編輯器選取、相機拖曳或動畫時間。
Pip 保存是否放置、格子位置、生命識別與實際餵食時間，載入後重新選擇行為。
AnimalSystem.status() 用 Date.now() 推導 6／12／18／24 小時邊界，不累加動畫 dt。
吃完後移除食盆並記錄 lastFedAt；24 小時未吃移除貓咪，health 歸零。
生命事件由 editor.consumeAnimalEvents() 立即寫入房屋或編輯草稿，並更新同一 lifeId
的撤銷快照，避免 Undo 重建已吃掉的食盆或倒轉時間；關頁後在下次載入補算到期。
保留 version 1 相容性：validate 移除舊 storage，補齊 animal.placed 與 care 欄位。
完整示例：house/presets/basic-house.json。
匯入限制：80 MB、400 格地板、800 面牆、200 件已放家具、最多一隻貓咪。

新增互動家具
1. catalog.js：新增 type、placement、size、interactionType。
2. SceneView.makeFurniture()：新增 placeholder 模型，或改成獨立資產 factory。
3. InteractionSystem.open() 路由 interactionType；action() 處理對應 UI actions。
4. 持久狀態放 object.customState；變更透過 controller.mutate()，
   使其進入撤銷、草稿、保存與匯出流程。
5. 自訂固定結構的狀態，在 HouseFeatures.validate() 加對應檢查；由 HouseModel.validate() 呼叫。
HouseEditor 核心不需要了解垃圾桶排班或新物件的業務欄位。

保存鍵和多人限制
音檔：IndexedDB roombloom-media-v1 / files，以 audio ID 保存 Blob。
MediaStore.pack() 隨房屋打包音檔；hydrate() 驗證並分配新音檔 ID，避免覆蓋其他房屋媒體。
SoundSystem 每房間只有一個播放來源；刪除音軌會釋放音檔並接續可用預設曲目；移除所有音響或離開房間會停止。
圖片壓縮後隨房屋資料保存，音檔不塞進 localStorage；有音響的房間會嘗試自動播放，拒絕時等使用者手勢重試。
roombloom-autoplay-v1:<roomId> 記住使用者手動暫停；上次關閉音樂時不自動重播。
Door.social 是本機示範狀態。切換室友收件匣不是身份驗證，也沒有發送網路通知。

原 App：roombloom-demo-v1
每房間：roombloom-house-v1:<roomId>
草稿：同上加 :draft
另一分頁保存時間戳不同時，阻止直接覆蓋。
這不是跨設備的協作鎖；接後端時可替換 SaveSystem 和成員 adapter，
不需要重寫幾何、碰撞或 A*。

個人任務擴充規則
所有會產生任務的新功能，必須透過 HouseTasks.register(name, provider) 加入來源。
Provider 接收 house/memberId/now/options；options.includeFuture 供行事曆查完整預約，只回傳該使用者未完成的任務；不可依 UI 正在看的室友切換。
回傳 {key,kind,title,description,source,dueAt,objectId?,sourceId?,completeLabel}。
key 必須包含來源 ID、提醒階段及期限，期限變更視為新提醒；同期限重開頁面不能再次響鈴。
HouseTasks.complete() 依來源更新資料，不另維護容易失去同步的任務副本。
Board 的 completedBy 保存每位成員進度，全部完成才設 completedAt；Board 的 My part done 同樣只完成目前成員。
預約在開始／結束前 30 分鐘進入清單；startedAt 用於轉換提醒階段，completedAt 釋放占用。
已接受的 Door 請求以 dueAt（舊資料預設 createdAt + 24h）產生提醒，recipient.completedAt 記錄個人完成。
PersonalTaskSystem 的 current member 由 mount options.memberId 提供，本機 App 固定 self；未來接帳號後替換。
roombloom-task-alerts-v1:<roomId>:<memberId> 保存至多 1,000 個已提醒 key，與 House JSON 分離。
每秒及 visibilitychange 補算期限，依 dueAt 重新排序；UI 最多三張。卡片只開啟詳情，由詳情中的完成按鈕修改狀態，沒有拖曳事件。
鈴聲使用本機 Web Audio 合成；未解鎖音訊時合併為一次待播放提示，首次手勢補響。
Pip 氣泡只讀第一項，約 2–4 分鐘提醒一次、到期再提醒；每幀投影角色座標，7 秒後消失。
Lighting 透過本機 Date.getHours()/getMinutes() 計算，SceneView 改光強與環境色；GridHelper 不依賴場景照明。

2026-10 操作、排程與照明
- ObjectSystem.moveCandidate/move 保留 id/customState/interactionConfig，先驗證目的地再原子搬移。
  桌子同步移動子物件 grid；Pip 保留生命與餵食資料。預覽保留原物件，取消不改房屋。
  state.movingId 只存在當次編輯；raycast 排除正在搬移的原物件及桌面子物件。
- R/M 在選取高度的 select 保留焦點時仍有效；打字欄位、modal 和修飾鍵不攔截。
- HouseFeatures.busy 由現在是否位於未完成預約時段決定；UI 每秒刷新按鈕，domain 也強制 busy→queue / idle→reserve。
- customState.bill={memberId,dueAt,repeat,anchorDay,note,paidAt}；HouseTasks 的 bills provider 派生付款提醒。
  月繳保留 anchorDay，短月夾至月底，下期恢復原日；付款補算到下一個未過期月份。
- customState.growth={placedAt,score,deadAt,history:[{key,at,memberId,title,delta,change,score}]}。
  HouseChores.settle 對所有負責人的未完成來源補算 3h 逾時，一個 member/task/deadline 只扣一次。
  complete 在變更來源前 settle、之後 record +1；歷史從放置開始，沒有截斷。
  delta 是獎扣分，change 是受 0/100 與死亡限制後的實際分數；history 含重算後餘額。
  preserveGrowth 更新同一盆栽的編輯歷史，避免幾何 Undo 倒轉時間扣分或重複獎勵。
  資料驗證檢查記錄格式、唯一鍵、排序、逐筆餘額與死亡狀態。
- HouseChores.arrangement 使用所有成員的 provider 與 includeFuture，合併共同任務、保留責任人。
  HouseTasks.forMember 卡片仍限目前 memberId；開另一成員 Info/Inbox 不切換身份。
- 每盞燈有 PointLight，可開關／調整 customState.light={on,brightness:0..2}；預設強度 32、距離 10。
  最多三盞同時計算動態陰影以控制 GPU 負擔，其他燈仍發光；少量環境補光保留暗部辨識。
  SceneView 處理光源／陰影資源釋放；預覽不建立真實光源。網格不受燈光影響。
- HouseFeatures.skyColor 依本機時刻插值清晨／白天／日落／夜晚；手動模式保留黑白亮度範圍。
- TaskBell.meow 使用 Web Audio 原創合成音，與鈴聲獨立音量節點，禁音可立即停止當次喵聲。
  roombloom-pip-mute-v1:<roomId>:<memberId> 本機偏好，不放入共享房屋 JSON。

最新預設與房間光影修正
- default-house.json 保存使用者提供的範本；default-house.js 內嵌相同 JSON，載入順序在 model.js 前。
  更新 JSON 後須同步產生 DefaultHousePreset 的 JS 資料。HouseModel.defaultHouse() 在複製時初始化
  cat lifeId/lastFedAt/health、plant growth、清空 machines 預約及舊請求；不改來源範本。
  SaveSystem 的空存檔與 Reset 使用 defaultHouse；basic() 留作原本幾何範例／測試 fixture。
- 移除 60×60 ShadowMaterial 接影平面；只有 floor/wall/furniture 會接收陰影。
  背景是 CSS 天空，不受室內 PointLight 及其遠距陰影影響，網格仍是獨立 unlit helper。
- 預约 Start 預設目前時間；未編輯的預設時間在每秒刷新保持有效，自訂未來時間不被蓋掉。
  busy 使用 min(startAt, startedAt)，提前確認開始也立即視為使用中；不可跨別人的時段提前開始。
  按鈕及 Running/Reserved 標記同時按實際時間刷新。
- Meow 音量存於 roombloom-pip-volume-v1:<roomId>:<memberId>，預設 .7。

物件擴充與模型資產
- fridge.customState.inventory=[{id,name,section:chilled|frozen,quantity:0..9999}]。
  初次新增必須大於 0；歸零保留項目供 ＋ 補入，確認狀態只存在互動視窗。確認補貨透過 HouseFeatures.addTask
  寫入已存在的 board.customState.tasks，由既有來源統一處理提醒／指派／完成／積分。

- H.isTable / H.tableSlots 统一 1×1 的 4 slots 與 2×1 的 8 slots，slot / 4 定位桌面單格。
  所有矩形地面物件以旋轉後 footprint 中心放置；桌面物件以桌的局部座標轉換。

  noScore 排除共享狀態提醒的差事獎扣分。
- custom-models.js 使用本機 vendor/gltf-loader-r180.js（官方 Three.js r180 GLTFLoader +
  BufferGeometryUtils，MIT，imports/exports 改為 classic-script closure，無新增 build 步驟）。
  預檢 GLB 格式、內嵌資源、大小／拓樸／層級限制，解析成靜態 mesh；不帶入相機與光源。
  custom.customState.model={id:model-*,name,bytes}，size 為動態 footprint / 最高三格的 bounds。

  匯入重驗資產、重新產生本機 model ID。預覽與已放模型用同一份 instance 尺寸計算。
- 縮圖用共用小型 renderer 從真正模型產生透明 PNG，快取每一型並在 SceneView.destroy 釋放 renderer。

- BloomDesign 在 app 前初始化 data-mood；roombloom-mood-v1 獨立保存 macaron / woodland。

  用 timeline.set 重定位至畫面下方並轉正，再直立升起；落定後只有 SVG 原地旋轉。
  route 變更時 cleanup 取消動畫；已完成的動畫由 Set 移除。resize 將開場完成並重新定位。
  prefers-reduced-motion 會略過開場／入場動畫，sessionStorage 記錄當次已播放狀態。

  等兩個 animation frame 讓 WebGL 繪製，再以不同位移／縮放速度散開前後雲層，不改相機或房屋資料。
  轉場期間 #app 暫設 inert，完成或換頁時恢復原值並移除 overlay；取消會清除 timeline、RAF 與 timeout。
  同房間重繪不重播；新進房、Archive 返回與記住房間的重新載入共用此路徑。
  reduced motion 或動畫庫缺少時直接掛載，播放途中開啟 reduced motion 也立即完成；6.5 秒保底解除操作鎖。
- communityPage() 組合共用返回、標題、房屋圖示與內容區；建立／加入／確認／邀請／收藏及 habits 共用。
