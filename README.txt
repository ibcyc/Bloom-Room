Bloom Room — 室友原型 + Isometric House Editor
============================================

快速啟動與 GitHub 上傳請先看 README.md。以下為完整操作手冊。

開啟方式
1. 完整解壓 Bloom Room 資料夾。
2. 保留 index.html、style.css、script.js、design.css、design.js、fonts.css、assets/、house/、vendor/ 的相對位置。
3. 雙擊 index.html，以支援 WebGL 2 的現代瀏覽器開啟。
   不需要 npm、安裝套件、建置或連接 CDN。Three.js、Anime.js 與網頁字型都已包含在資料夾。
4. VS Code：File → Open Folder，開啟整個 Bloom Room 資料夾。
   修改後儲存，刷新瀏覽器即可。

進入房屋
輸入 ID → Welcome → My Community → Create / Join / Load → 房屋。
既有的找室友、習慣問卷、個人資料和模擬邀請流程仍可使用。
示範加入碼：RB42（2 名原始成員）、SUNNY3（3 名）、FULL4（已滿）。

設計與動畫
- 依 ui reference 的手繪、圓角、虛線欄位與留白設計，套用到登入、大廳、表單、配對、Archive 及房屋控制項。
- 初次開啟有 Our Home → Bloom Room → Login 的動畫；鑰匙先保持橫向飛出右側並消失，
  再由畫面下方直立升起，停妥後緩慢轉動。兩段飛行之間不在畫面內轉向。
  Skip to login 可跳過；登入畫面的 Replay the welcome 可重播。減少動態效果偏好會直接顯示登入。
- 登入後的 Mood 下拉選單可切換 Mood 1 · Macaron / Mood 2 · Woodland，選擇跨重新整理保留。
  房屋左上角也有選單；天空仍追隨實際時間，日間背景輕微混合所選 Mood，手動亮度不受影響。
- 建立／加入房間、加入確認、邀請、房屋收藏及生活習慣表單共用置中的紙張版面。
  欄位與主要操作左對齊；手機按鈕展開為整行。Demo 邀請可展開選房並帶入邀請碼。
- My Community / Find a Roommate 在同一畫面展開，黃色選項向上滑入，上方卡片及導覽列保持原位。
  支援快速切換及瀏覽器上一頁／下一頁；減少動態效果模式會直接展開。
- 登入後以鑰匙取代滑鼠游標，涵蓋大廳、表單、Archive 與彈窗；進入房間及登出後恢復原游標。
  觸控操作不顯示跟隨游標；滑鼠離開視窗會隱藏鑰匙。導覽列已調薄，保留 Mood 與 My Profile。
- 進入房間時先由雲霧覆蓋畫面，房間繪製後，前後兩層雲向外掠過並散開；配合兩種 Mood 與手機畫面。
  離開房間時播放反向雲層動畫，編輯／保存不會重播；減少動態效果模式直接切換。
- Our Home / Bloom Room 開場使用 Barriecito，細長按鈕使用 Amatic SC；其餘標題與內文使用 HanziPen TC / Caveat。
  尚未提供 HanziPen TC 網頁字型檔，因此未安裝該字型的裝置以本機 Caveat 後備顯示。
- My Community → Load your Room：點小房子預覽實際房間縮圖，房屋名稱顯示在虛線上方。
  Leave & archive 經確認後退出房屋並保存縮圖；Archive 可查看與重新加入（仍受四人上限限制）。
  房屋配置、媒體與互動資料留在原房間存檔，不會因 Archive 刪除。
- 測試：node tests/design.test.cjs（Playwright + Chrome）；涵蓋動畫、Mood 保存、既有表單／配對流程、
  Archive 往返、手機版、減少動態效果與 file:// 離線開啟。
  node tests/hub-navigation.test.cjs 驗證選單原地展開、游標切換、彈窗及精簡導覽列。
  node tests/room-entry.test.cjs 驗證雲層轉場、切頁取消、記住房間、兩種 Mood、手機與減少動態效果。

重置整場 Demo
- My Profile → A fresh demo → Reset demo：按一次直接回到開場動畫及空白 ID 登入。
- 清除目前瀏覽器、目前網址下的示範個人資料、所有房屋／Archive／草稿、任務、上傳素材、Mood 與其他偏好。
  有要保留的房屋時，先在房屋編輯選單 Export 匯出。按鈕不會修改程式、素材檔案或 default layout JSON。
- 與房屋編輯模式中的 ! Reset 不同：! Reset 只重設當前房屋的草稿，不重置整個 Demo。
- 同一網址的其他 Bloom Room 分頁也會回到登入，停止舊房屋與音樂，避免把草稿重新寫回。
  其他網站、其他瀏覽器及其他網址的存檔不受影響。
- 測試：node tests/demo-reset.test.cjs（Playwright + Chrome）；只在隔離瀏覽器驗證，不清除使用者的實際資料。

Our Room 現在是實際的 Three.js 等角房屋：
- 房間在全螢幕畫布中置中，沒有側欄或固定的說明文字；個人任務以左側少量卡片呈現。
- 上方中央為低透明度 House name；右上角為旋轉箭頭（相機復位）與 Help 圖示。
- 右下角透明背景的半透明齒輪進入 Edit mode，滑鼠靠近時恢復不透明；左下角離開房間。
- 右側預設只顯示自己的頭像（外圈標記）及 Pip；懸停／鍵盤聚焦頭像展開所有室友，自己在最上方。
  點成員可開本機 Inbox，再點 Info 看個人資料；這不會切換目前使用者。
- 進入編輯後使用底部三層選單。登入狀態與最後的房間記在本機，
  下次從網站首頁開啟會直接進入上次房間；明確的其他頁面連結仍照常開啟。
- 家具就是功能入口：垃圾桶、洗烘機、音響、牆上留言板、畫框及門。
- 點擊沙發／床／食盆可叫 Pip 前往；Sprout 顯示差事積分與歷史；壁燈／落地燈可開關與調整亮度。

編輯選單
- 最底部固定 SAVE：直接按下儲存並離開編輯；懸停展開 Export | SAVE | Import，
  SAVE 本身保持原位。手機會直接顯示 Export / Import。
- SAVE 上方為 Object / Structure 切換，右側紅色 ! Reset 可重置房屋。
- Structure 上方有 Type 與 Texture；Object 的 ＋（Add object）會開啟新增物件選單。
- Structure 未選放置類型時，按鈕只顯示 Type，不預選或記憶上一個類型。
- Structure 的 Type 懸停或點按向上展開 Wall / Door / Floor；鍵盤也可 Tab 與方向鍵選擇。
- 完成一次建造點擊／拖曳、放置一件物件、取消或切換模式後，Type 會清空；
  下一次放置須重新選擇。按住左鍵的同一筆拖曳仍能連續建造。
- Object / Structure、預覽方向、Texture 預設與顏色、壁掛高度仍會記在本機。
- Type 和 Texture 是工具狀態；Esc 返回左鍵選取。沒有 Select Items 或 Direction 選單。

建造
- Structure：從 Type 選 Wall / Door / Floor，長按左鍵拖曳連續放置、長按右鍵拖曳連續移除。
  一整筆拖曳算一次編輯，可一次撤銷。
- 空白房屋的第一塊地板放在金色起點 (X=0, Z=0)。
- 新地板必須與現有地板共邊，不能只碰角。
- 牆依附地板的 North / West 後側邊緣；後續牆必須接到既有牆的端點。
  這兩個方向對應固定視角的後側，可建立後牆和內部分隔牆。
- 門只能依附既有牆。門固定關閉，貓咪不能穿越。
- 刪除會把地板拆成不相連兩部分的格子時，會提示先從外圍拆。
- X/Z 的編輯範圍是 -8 到 11；位置為整數網格。

物件、植物與貓咪
- Object → ＋ → 選物件，選單自動關閉。
- 模型隨游標預覽；綠色代表可放置，紅色表示不合法並說明原因。
- 左鍵放置一次後回到選取；要放下一件，請重新選擇家具。
- 預覽中按 Esc 或右鍵會取消，不會刪掉游標下已放置的物件。
- 平時右鍵直接刪除物件，沒有 Storage。選取後按 M 搬移，保留照片、預約、積分及所有設定；Esc／右鍵取消搬移。
  搬移桌子會連同桌面物件搬移；搬移 Pip 保留原有餵食時間。
- 地面家具占 1×1 格，不能重疊或懸空。桌子提供四個桌面位置，可放 Sprout 或 Speaker。
  游標移到桌面選位置；刪除桌子會連同上方物件刪除，Undo 可一起恢復。
  食盆只能放地板，不能放桌上。
- 壁掛物件需要牆；放置壁掛時 Height 可選 1 / 1.5 / 2 公尺。
- R 旋轉目前預覽，或選取／游標下的家具。R／M 依實體鍵辨識，中文輸入法下也能使用；文字欄位輸入時不觸發。
- 沒有置放預覽時，左鍵直接選取物件。藍色覆色、外框和選取提示標示目前選取項目；
  點房屋外空白處取消選取。編輯時不會開啟日常互動。
- 拆除地板、牆或建立門導致物件失效時，直接移除；Ctrl+Z 可恢復。
- Pip 可從 ＋ 選單放置，最多一隻；已有貓咪時選項變灰。
- 右鍵可刪除 Pip。失去地板或被新家具覆蓋時也會移除，不會自動搬家。
- Undo / Redo 保留最近 30 次編輯，含整筆拖曳、刪除物件與貓咪。

家具互動（一般房間模式）
- Sofa / Bed：Pip 前往並跳上座面／床墊休息。
- Trash can：安排室友次序、每隔 1 小時至 30 天倒一次，顯示下一次期限；
  Mark done 推進到下一位，從完成時間重新計算下次期限。
- Food bowl：Pip 自動尋找可到達的食盆，吃完移除食盆並回到 full。
- Wall art：選擇放置時上傳 PNG／JPEG／WebP，或先放空框；空框第一次點擊只提供上傳。
  圖片設定後不能替換，再點顯示小預覽，按 × 或 Esc 關閉。圖片會縮至最長邊 640 像素。
- Washer & dryer：同一彈窗上方烘衣機、下方洗衣機，分開保存預約與佇列。
  可預約未來 90 天內的時段，選室友並輸入 1–1,440 的整數分鐘數，例如 43；同機器不可重疊。預設立即開始，Start 可以另選未來時間。
  機器正在使用時 Reserve 禁用，只能 Join Queue；閒置時不顯示 Join Queue。
  Join Queue 尋找現在起第一個足夠的空檔，Cancel 釋放該預約時段。
- Oven：新增地面烤箱，使用與洗烘機相同的預約、排隊、自訂分鐘數及個人提醒。
- Speaker：一個主要播放／暫停按鈕、上一首／下一首、進度、音量及循環設定。
  音量與循環立即生效，不用另按 Save；點歌名播放，最多加 10 首自訂音檔（每檔 10 MB／1 小時）。
  房內有音響時會自動播放；若瀏覽器阻擋，第一次點擊／按鍵後啟動。手動暫停狀態會記住。
  預設歌單是 HoliznaCC0 的 First Snow、Laundry On The Wire、Keeping Cool，
  音樂以 CC0 公開並存於本機。來源與授權見 house/audio/CREDITS.txt。
- Door：保存 Public room 偏好，展開 Roommate requests 寫留言及選擇接收室友。
  頭像顯示未回覆數；點室友頭像可在本機模擬收件匣接受或拒絕。
  目前設定不會把房屋公開上網，也不會向其他裝置發送通知；之後再接跨裝置服務。
- Message board：壁掛待辦清單，短描述、可複選室友、指定完成期限；可完成、重開及刪除。
- Window：黑至白的光線拉桿，立即預覽並保存；Follow current time 跟隨裝置本機時間，
  中午最亮、夜晚變暗。即使最暗時，編輯模式的網格線仍保持可見。
  Outside the window 可選晴、雨、雪，或 Automatic 隨機天氣；每次自動狀態維持 30–60 分鐘。
  天氣選擇與下次變換時間隨房間保存，重開後不會重新抽選；長時間離線只推進到一個新狀態。
  窗格顯示天空，室外有輕量雨雪動畫。天氣層在房間後方，牆壁、地板與家具都能擋住；
  不遮擋室內、不攔截操作。減少動態效果偏好會顯示靜態天氣。
- Sprout：初始 100 分，完成個人任務 +1；超過截止 3 小時未完成，每位負責人各扣 1，
  同一期限只扣一次。0–100 封頂封底，0 代表死亡、需重新放置。
  顯示最近紀錄、室友淨積分與可捲動完整歷史，含放置時間。重新開頁會補算逾時，不重複扣分。
- Electricity bill / Water bill：壁掛閃電／水滴，設定截止時間、負責人、備註、每月或單次。
  完成付款後，每月帳單自動推進下期（保留月底日期）；加入個人任務及排程。
- Wall lamp / Floor lamp：可開關、設定亮度，提供暖色實際光源和家具陰影。
- 編輯時停用家具日常互動；畫框首次圖片設定屬放置流程。

個人任務與貓咪提醒
- 左側第一張方形任務卡的中心在畫面中間，後面依序往下縮小、淡出，最多三張；矮螢幕最多兩張。
- 卡片只列目前使用者（本機示範為 self）的任務，依期限排序；新加入且更早截止的任務會插到前面。
- 來源包括留言板指派、倒垃圾輪值、洗衣／烘衣／烤箱預約、已接受的室友請求。
- 預約開始及結束前 30 分鐘出現提醒。開始卡內按 I have started 表示已開始，之後會在結束前出現取回物品提醒；
  結束卡提早完成會釋放該預約占用。若錯過開始提醒，會直接顯示結束提醒。
- 點卡片看來源、內容、期限及預約時段；在詳情內按完成按鈕；沒有滑動完成操作。
  詳情內也有完成按鈕。多人共同指派時，只完成自己那一份，不會替別人完成。
- 到期卡變紅並發出一次鈴聲；通知紀錄以房間／使用者隔離，重開不會反覆響同一項。
  網頁關閉時無法發聲；回到頁面補算過期項目。聲音若被瀏覽器限制，首次操作後補響。
- Pip 偶爾用跟隨角色的小氣泡提醒第一張任務；該任務到期也會提醒一次。
  只讀目前使用者的任務，不因查看其他室友收件匣而切換提醒對象。
- 編輯時隱藏任務列與氣泡；到期仍會記錄並響鈴。刪除來源物件或取消預約會同步撤掉對應任務。

材質
- Structure → Texture → 選 Preset（Wood / Plaster / Tile）與 Color。
- 左鍵點地板／牆／門套用；右鍵恢復該物件的預設材質。
- Wood、Plaster、Tile 使用本地程序材質，不需下載圖片。
- 材質資料獨立保存；更換材質不會重建整個房屋幾何。

相機、鍵盤與手機
- 在房屋外空白處按住左鍵或右鍵拖曳，即可平移；也支援中鍵拖曳。
- Structure 在有效建造格開始拖曳，會優先建造；可從既有地板拖向外側延伸。
- 滾輪／觸控板捲動縮放；手機支援房屋外單指平移及雙指縮放。
- 右上角 Reset angle：重新置中，配合目前螢幕大小取景。
- R：牆／門預覽切換後側方向（門需要該方向的牆）；地板旋轉紋理；物件旋轉 90°。Esc：取消放置預覽並返回 Select。
- Ctrl+Z：撤銷；Ctrl+Shift+Z：重做。Mac 同時支援 Cmd+Z / Cmd+Shift+Z。
- 快捷鍵不會攔截文字輸入和對話框。
- 畫布取得焦點時不再顯示瀏覽器藍色外框；按鈕仍保留鍵盤焦點提示。
- Help 只保留在右上角；沒有 Grid controls、旋轉或 Undo / Redo 按鈕。
- 底部選單不需橫向捲動，SAVE 保持在最下方。

Pip 的移動
- Pip 透過物件選單放置，但使用獨立的動態角色與尋路系統。
- Edit mode 暫停隨機遊蕩，但放置可到達的食盆仍會自動走過去吃。
- 完成行為後，隨機遊蕩或尋找可到達的沙發、床、食盆。
- A* 只經過有效地板，避開家具、牆和關閉的門；舊的開門資料會轉為關閉。
- 比較可達的互動點，先前往合法相鄰格；沙發／床會跳上座面／床墊休息，
  離開時再跳回走道。直接點沙發或床可指定該件家具，沒有額外 Find / Wander 選單。
- 食盆優先於隨機遊蕩；吃完食盆會消失，並立即保存最後餵食時間。
- 結構改變會重新檢查路徑；站立格失效時直接移除，之後可重新放置。

Pip 的狀態
- 右側貓咪圖示可查看 Hunger 與 Health（初始 100）。
- 以最後吃完的實際時間計算：0–6 小時 full、6–12 小時 ok、12–18 小時 hungry、
  18–24 小時 horrible 並顯示倒數，滿 24 小時未餵食就移除貓咪。
- 關閉網站後時間仍會累積，重開時補算；舊存檔第一次載入會初始化計時。
- 吃完與到期狀態立即保存，編輯中的變化保存於草稿。Undo／Redo 不會恢復
  同一隻貓咪吃掉的食盆，或把牠的餵食時間倒轉。重新放置貓咪會開始新計時。

保存、匯出、匯入
- SAVE：保存完整 House Definition 並離開編輯模式，包含結構、門、家具、
  材質、互動設定，以及 Pip 的位置、生命識別、最後餵食時間與健康值。
- Export：顯示完整 JSON，可 Download .json 或 Copy JSON。圖片和自訂音檔一併匯出。
  音檔平時存 IndexedDB；匯入時重新存入本機媒體庫。單份 JSON 上限 80 MB。
- Import：選擇檔案或貼上 JSON → 驗證 → 確認取代目前草稿。
- 檢查版本、ID、網格、附件、占格、材質與互動資料。
  不合法的內容只顯示錯誤，不會取代目前房屋。
- Reset：選擇空白房屋或最新預設房屋；重置草稿後可用 Ctrl+Z 撤銷。
- 舊版存檔會保留已放置內容、移除退休的倉庫資料；新匯出不含 Storage。
- 每個房間的房屋分開存於 localStorage，另有未保存草稿的本機恢復。
- 同一房間被另一分頁保存時，會阻止直接覆蓋，提示先匯出草稿。
- house/presets/basic-house.json 和 empty-house.json 可直接匯入。
  匯出與 Runtime 使用同格式，可作為未來 Default House Preset。
